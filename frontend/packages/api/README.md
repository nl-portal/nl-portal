# @nl-portal/nl-portal-api

[![NPM](https://img.shields.io/npm/v/@nl-portal/nl-portal-api.svg)](https://www.npmjs.com/package/@nl-portal/nl-portal-api)

Part of the [NL Portal](https://github.com/nl-portal/nl-portal) frontend libraries, a collection of
packages providing a configurable portal implementation for municipalities.

This package contains the GraphQL layer used to talk to the NL Portal backend: the Apollo client
provider, the generated GraphQL types, and the queries and mutations used by the other NL Portal
packages.

## Install

```bash
npm install --save @nl-portal/nl-portal-api
```

## Documentation

See [nl-portal.nl](https://nl-portal.nl) for setup, configuration, and architecture.

Source, issues, and contribution guidelines live in the
[nl-portal/nl-portal](https://github.com/nl-portal/nl-portal) repository.
