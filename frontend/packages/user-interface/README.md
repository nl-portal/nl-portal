# @nl-portal/nl-portal-user-interface

[![NPM](https://img.shields.io/npm/v/@nl-portal/nl-portal-user-interface.svg)](https://www.npmjs.com/package/@nl-portal/nl-portal-user-interface)

Part of the [NL Portal](https://github.com/nl-portal/nl-portal) frontend libraries, a collection of
packages providing a configurable portal implementation for municipalities.

This package contains the user interface of the portal: the reusable components, pages, and layouts
that make up a portal implementation. The components follow the specifications of the
[NL Design System](https://designsystem.gebruikercentraal.nl/) and can be restyled through design
tokens.

## Install

```bash
npm install --save @nl-portal/nl-portal-user-interface
```
