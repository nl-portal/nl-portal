# @nl-portal/nl-portal-authentication

[![NPM](https://img.shields.io/npm/v/@nl-portal/nl-portal-authentication.svg)](https://www.npmjs.com/package/@nl-portal/nl-portal-authentication)

Part of the [NL Portal](https://github.com/nl-portal/nl-portal) frontend libraries, a collection of
packages providing a configurable portal implementation for municipalities.

This package handles authentication for the portal. It provides the OIDC context, the OIDC callback
page, and the wrappers and hooks used to protect the application and to log users out.

## Install

```bash
npm install --save @nl-portal/nl-portal-authentication
```
