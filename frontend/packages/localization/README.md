# @nl-portal/nl-portal-localization

[![NPM](https://img.shields.io/npm/v/@nl-portal/nl-portal-localization.svg)](https://www.npmjs.com/package/@nl-portal/nl-portal-localization)

Part of the [NL Portal](https://github.com/nl-portal/nl-portal) frontend libraries, a collection of
packages providing a configurable portal implementation for municipalities.

This package handles localization for the portal. It provides the locale context and provider, the
default Dutch and English message bundles, and the hooks used to format dates and labels.

## Install

```bash
npm install --save @nl-portal/nl-portal-localization
```

## Documentation

See [nl-portal.nl](https://nl-portal.nl) for setup, configuration, and architecture.

Source, issues, and contribution guidelines live in the
